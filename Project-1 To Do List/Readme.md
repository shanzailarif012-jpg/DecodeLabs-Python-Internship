## About
A simple console-based To-Do List app made in Python. It lets you add tasks and view them using a list.

## Features
- Add a task
- View all tasks (numbered)
- Exit the program

## Concepts Used
- Lists (`append()`)
- `while` loop
- `if / elif / else`
- `enumerate()`

## How to Run
```bash
python To_Do_List_main.py
```

## Menu
```
1: Add Tasks
2: View Tasks
3: Exit
```
